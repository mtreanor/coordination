# Information limits are enforced in the Briefing, not in RUE rules

RUE rules may read any fact, including ground-truth work state mirrored from the work, such as every agent's inventory. What an agent is allowed to know is enforced solely by what goes into its Briefing: its own view of the work, the public work state, and a templated rendering of its own private store, never another agent's store or hidden ground truth. Whether a given judgement action or rule reads ground truth or only what an agent observed is a per-rule authoring choice, which matters for how judgements diverge between agents.
